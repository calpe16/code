# Research and operational evidence

| Area | Evidence available | What remains unproven or private |
|---|---|---|
| Costs and FX | Fixed Decimal examples with hand calculations and tests | Not a multicurrency cash ledger or actual fills. |
| Drawdown and temporal partitions | Synthetic equity data, helpers and tests | Does not establish absence of look-ahead in the whole system. |
| Daily returns and partial exits | Two functions extracted from the project | Conventions and trade identity assumptions in the methodology note. |
| Research decisions | A documented hypothesis that was not promoted | Underlying market data and full selection process not redistributed. |
| Orders, fills, reconciliation, reports | Five real Streamlit captures using an isolated fixture | Rendering and a queued pause request tested; real execution not tested. |
| Audit and controls | Visible audit records and request acknowledgement | An acknowledged request is not an executed engine command. |
| Live-operation architecture | Reviewed in the private project | No sustainable live advantage or completed operational acceptance claimed. |

The source and configuration of the wider trading system remain private. The sample is intentionally useful without disclosing current strategy rules or personal account details.
