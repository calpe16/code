# Application gallery

The [product tour](../docs/PRODUCT_TOUR.md) contains 12 desktop views and three phone-width views, generated from the app's widgets with synthetic data. Three earlier financial renders use a separate fixture: [summary](app-summary.png), [movements](app-movements.png), [review](app-review.png).

The new gallery was generated by one local Flutter widget test without reported widget exceptions. The home uses the full app shell; most module captures use a labelled outer frame. The [import walkthrough](WALKTHROUGH.md) is an illustration of the CLI decisions.
